# 资产工作台

模型目录显示登记了 GLB 的物件。打开「配置、投票与下载」，可以对当前版本投票或留言，也可以为物件添加可搜索、可筛选的标签。

选择模型版本、各材质槽的底色贴图和动作，预览完成后加入「待下载清单」。同一个模型可以用不同配置加入多次。每条配置在 ZIP 中有独立目录，GLB 内嵌选择的资源，导出用原分辨率文件。待下载清单在当前页面维护。[在 Unity 中使用下载包](UNITY-ASSET-IMPORT.md)

默认评阅记录保存在当前浏览器。要让同一台机器的多个浏览器共用评阅记录，可以为本机 Node 服务设置 `ASSETS_TEAM_CONFIG`，指向程序目录之外的配置：

```json
{
  "stateFile": "./workbench-state.json",
  "projects": [{"projectId":"demo-a","datasetId":"example-v1"}]
}
```

配置后重启，所列目录在本机共享评阅。新记录使用同一个本机身份，每个模型版本可以改票、撤票或留言。旧状态文件里的记录继续保留。
